        La prueba de que funciona

        Campeones actuales: red neuronal (MLP) para velocidad y LightGBM para alerta de colapso, entrenados con la serie ARS.

        Cómo se eligió el modelo

        Se entrenaron varios candidatos para cada tarea y se eligió el ganador con reglas fijadas antes de ver los resultados. El holdout 2026 mide cuánto se sostiene el modelo en un periodo que no se usó para elegirlo.
